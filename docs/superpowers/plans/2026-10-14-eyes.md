# XDOG Eyes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. No subagents are authorized by this plan.

**Goal:** Deliver a skill-driven, declarative file observer that notifies an existing coding session without teaching the coding harness about file sources.

**Architecture:** Follow flow's frozen models, load/validate boundary, asynchronous executor, replaceable adapters, CLI and packaged skill. Eyes runs independently and talks to a source-agnostic local host protocol; coding owns admission, scheduling, permissions and session history. The finite workflow executor is not reused for continuous observation.

**Tech Stack:** Python 3.12+, standard-library dataclasses/JSON/asyncio/argparse/Unix sockets, uv workspace, Hatchling, pytest, Ruff, strict mypy. No runtime dependency from eyes to agent/ai/coding/claw/flow.

**Spec:** `docs/superpowers/specs/2026-10-14-eyes-design.md`

## Global Constraints

- Package `packages/eyes`, distribution `xdog-eyes`, namespace `xdog.eyes`, CLI `xdog-eyes`, skill `eyes-observers`.
- Version 1 JSON definitions; reject unknown fields/types, invalid references and invalid numeric values.
- Relative source roots resolve against the definition file's directory.
- Session-level registrations, no persistent daemon, no automatic harness startup and no crash replay.
- Default polling 1,000 ms, debounce 500 ms, maximum batch delay 2,000 ms.
- Default maximum 10,000 matching files and 10 MiB per file; both configurable positive integers.
- No symlink following, nonregular files, arbitrary scripts, network listener or LLM detector.
- Maximum 128 pending route items, 256 paths per item, 1 MiB wire messages and 4,096 accepted delivery IDs per generation.
- Retry from 250 ms to 5 s; heartbeat every 5 s and stop after 15 s without confirmed host ownership.
- Exactly one automatic external-event turn per host context after explicit human input or approved resume; model-originated resume does not replenish this budget without approval.
- Private capability directory mode 0700 and descriptor mode 0600; no token in CLI output, definitions or model prompts.
- Coding's existing fail-closed permission policy remains authoritative; no new allow-all shortcut.
- Implement interactive and RPC scheduling; print mode rejects session-bound monitoring.
- First release is Unix-local; describe polling gaps and lack of historic file content honestly.
- Run development commands from the repository root and preserve unrelated changes.

## Review Focus

1. An editor replaces a regular file with a symlink during scanning: never follow it or treat a transient read error as deletion. Pin in Task 2.
2. A lost ACK repeats a delivery after a context switch: neither execute it twice nor admit it to the replacement session. Pin in Tasks 4 and 5.
3. A real human submission races automatic dispatch while compaction/children are active: retain human priority and do not overlap session owners. Pin in Task 6.
4. Concurrent CLI starts or cancellation during baseline leave orphan processes: one runtime, awaited scans and prompt cleanup. Pin in Task 7.
5. Attacker-controlled evidence contains terminal escapes, fake instructions or oversized JSON: reject invalid frames and display safely without changing registered instructions. Pin in Tasks 4, 5 and 6.

## Shared interfaces

These signatures are the contract between tasks. Domain types are frozen dataclasses with tuple collections. JSON conversions return validated standard-library JSON objects; no `Any` escapes public interfaces.

```python
# eyes.models
EventType = Literal["file.created", "file.modified", "file.deleted"]

@dataclass(frozen=True)
class FileState:
    digest: str
    size: int

@dataclass(frozen=True)
class FileEvidence:
    path: str
    before: FileState | None
    after: FileState | None
    observed_at: float

@dataclass(frozen=True)
class Event:
    id: str
    source_id: str
    detector_id: str
    type: EventType
    observed_at: float
    evidence: tuple[FileEvidence, ...]

# SourceDef, DetectorDef, HandlerDef and RouteDef carry the fields in the spec.
# ObserverDef contains version/name and tuple collections of those definitions.
def load(path: Path) -> ObserverDef: ...
def parse(data: object, *, base_dir: Path) -> ObserverDef: ...

# eyes.sources.file
@dataclass(frozen=True)
class FileSnapshot:
    entries: tuple[tuple[str, FileState], ...]

def scan(source: SourceDef) -> FileSnapshot: ...

# eyes.detectors.file_change
class FileChangeDetector:
    def __init__(self, definition: DetectorDef) -> None: ...
    def observe(self, snapshot: FileSnapshot, *, now: float) -> None: ...
    def flush(self, *, now: float) -> tuple[Event, ...]: ...

# eyes.executor
@dataclass(frozen=True)
class Delivery:
    id: str
    registration_id: str
    route_id: str
    instruction: str
    events: tuple[Event, ...]

class Registration:
    id: str
    definition: ObserverDef
    async def aclose(self) -> None: ...

# Caller supplies scan and delivery adapters; production defaults are separate.
async def observe(
    definition: ObserverDef,
    *, registration_id: str,
    scanner: Callable[[SourceDef], Awaitable[FileSnapshot]],
    deliver: Callable[[Delivery], Awaitable[str]],
    emit: Callable[[RuntimeEvent], None],
    clock: Callable[[], float],
    sleep: Callable[[float], Awaitable[None]],
    cancel: asyncio.Event,
) -> None: ...

# transport/client and host use JSON protocol v1, not shared eyes classes.
class HostClient:
    async def request(self, message: dict[str, JsonValue]) -> dict[str, JsonValue]: ...
    async def aclose(self) -> None: ...
```

Implement the runtime and tests using these names; revise the plan explicitly if a better interface is required rather than inventing incompatible interfaces downstream.
