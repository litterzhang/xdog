Eight composable Python packages for local-first model APIs, Agents, terminal applications, typed workflows, observations and skills. Each host owns its execution and permissions; no hosted control plane or external database is required.

Linux and Python 3.12+. Durable features use local files and SQLite. Real model calls require an authenticated, configured provider.

Choose an entry point

pip install xdog-coding xdog-claw xdog-flow xdog-eyes
xdog-ai login copilot
xdog-ai models copilot --sync
xdog-coding --permission-mode ask

Install these packages in the same environment for installed capability discovery. Coding and Claw include xdog-skills. Flow and Eyes provide their own discoverable skills and CLI-backed tools; skill bodies are not activated by default.

Eight distributions publish to PyPI. This site is the ninth workspace package: use uv sync --locked and uv run xdog-site in a checkout.
